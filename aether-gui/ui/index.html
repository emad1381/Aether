Transport Protocol

Select how Aether connects through restricted networks

Available Transports

MASQUE (HTTP/3)

QUIC over UDP. Recommended, fastest handshake and resilient to packet loss.

MASQUE (HTTP/2)

TLS over TCP. Appears as standard HTTPS web traffic. Use when UDP is throttled.

WireGuard

Classic lean WireGuard tunnel. Fast and lightweight on open UDP networks.

WARP-in-WARP (gool)

Two nested WireGuard layers. Bypasses single-hop WireGuard fingerprinting.

MASQUE-in-MASQUE

Two nested MASQUE hops. Dialed from inside the edge for a different exit IP.

Tor (Chain)

Tor carried inside the WARP tunnel. Your network never sees Tor traffic.

Tor (Reverse)

Tunnel dialed through Tor on HTTP/2. WARP edge reached from a Tor exit.

Tor Only

Direct Tor proxy with automated pluggable transport bridge fetching.

Scanner & Obfuscation

Configure endpoint discovery and deep packet inspection evasion

Scan Mode

Turbo

Fastest. Connects to the first responsive verified gateway.

Balanced (Default)

Tests multiple candidates and picks the lowest ping.

Thorough

Deep range sweep across subnets to find the lowest possible RTT.

Stealth

Slow, quiet probe cadence for networks monitoring port scans.

Ironclad

Full tunnel + real HTTP request per candidate. Guaranteed working.

Obfuscation Noise Profile

Firewall (Balanced)

Recommended. Pads handshakes with randomized decoy noise.

GFW (Aggressive)

Heavy packet-shaping and timing jitter for strict DPI.

Light

Minimal padding with minimal latency overhead.

Off

No packet padding or noise injection.
